# 部署指南（Cloudflare Pages 版）

从零到线上，全程免费、不用买服务器、不用买证书。按顺序做，每步都有验证方法。

---

## 先回答几个常见疑问

**1. 为什么推荐 Cloudflare Pages 而不是 GitHub Pages？**

| | Cloudflare Pages | GitHub Pages |
| --- | --- | --- |
| 费用 | 免费 | 免费 |
| HTTPS | 自动 | 自动 |
| 国内访问 | 明显更稳 | 一般 |
| 点赞 / 阅读量 / 在线人数 | ✅ 支持（边缘函数 + KV） | ❌ 只能本地记录 |
| 私有仓库部署 | ✅ 支持 | ❌ 免费版必须公开仓库 |
| 自定义域名 | 免费自带 | 免费，证书偶尔要等 |

关键差别就是第一行的动态功能——本项目已经写好了统计接口，Cloudflare 上开箱可用。

**2. 域名是必需的吗？**
不是。Cloudflare 会免费给你一个 `项目名.pages.dev`，HTTPS 自动开。域名只影响好不好记，以及以后换托管商时链接不变。**先上线，以后再买域名也不影响代码。**

**3. HTTPS 要自己弄吗？**
不用。部署后自动签发和续期。我们本地预览用的 `http://127.0.0.1:4321` 只是你电脑上的开发服务，没上公网，属于正常现象。

**4. 仓库要公开吗？**
Cloudflare Pages 支持从**私有仓库**构建，你可以不公开源码。

## 第 0 步：本地确认

```bash
npm install
npm run dev          # → http://localhost:4321
```

改 `src/config.ts` 换站名、作者、问候语、背景风格；把 `src/content/blog/` 里的示例文章换成你自己的。

---

## 第 1 步：推到 GitHub

```bash
cd my-blog
git init
git add .
git commit -m "init blog"
git branch -M main
git remote add origin https://github.com/你的用户名/你的仓库.git
git push -u origin main
```

仓库公开或私有都可以。

---

## 第 2 步：连接 Cloudflare Pages

1. 打开 [Cloudflare Dashboard](https://dash.cloudflare.com/) → 左侧 **Workers & Pages**
2. **Create** → **Pages** → **Connect to Git**
3. 授权 GitHub，选中刚才的仓库
4. 构建配置填：

   | 字段 | 值 |
   | --- | --- |
   | Framework preset | `Astro` |
   | Build command | `npm ci && npm run build` |
   | Build output directory | `dist` |

5. 展开 **Environment variables (advanced)**，加一条：

   | 变量名 | 值 |
   | --- | --- |
   | `SITE_URL` | `https://你的项目.pages.dev`（拿到正式域名后再改） |

   > ⚠️ **不要**设置 `BASE_PATH`。Cloudflare Pages 站点在根目录，设了会导致链接多加一层前缀。

6. **Save and Deploy**，等 1~3 分钟

**验证清单**：拿到 `https://你的项目.pages.dev` 后，

- [ ] 地址栏有 🔒（HTTPS 已生效）
- [ ] 首页先出现入场加载页（细字站名 + 下拉进入主页），下拉或点击后进入正文
- [ ] 进入后是「左内容 + 右边栏」布局，边栏能看到头像、姓名、签名和社交图标
- [ ] 边栏导航能进「分类」「友链」页
- [ ] 按 `/` 能搜到文章
- [ ] 右上角能切换亮/暗主题

---

## 第 3 步：让点赞 / 阅读量 / 在线人数真正生效

统计接口在 `functions/api/stats.ts`，需要一个 KV 存储来记数据。

1. Cloudflare Dashboard → **Storage & Databases** → **KV** → **Create instance**
2. 名字随便填，例如 `blog-kv`
3. 回到 Pages 项目 → **Settings** → **Bindings** → **Add** → 选 **KV namespace**
4. **Variable name 必须填 `BLOG_KV`**（代码里写死的名字），KV namespace 选刚建的那个
5. 回 **Deployments** → 找到最新一次 → **Retry deployment**

**验证**：打开一篇文章，底部显示阅读量 / 在线人数 / 点赞。点个赞数字 +1，换个浏览器打开能看到同一个数字，页面上的"本地预览环境"提示消失。

> 没绑定前页面也能正常看，只是数字存在浏览器本地。

---

## 第 4 步：配置评论区（Giscus）

评论由 GitHub Discussions 提供，和托管商无关，**不占服务器**：

1. 新建一个**公开**仓库，例如 `blog-comments`，专门放评论数据（和博客源码仓库分开，将来换主题也不影响评论）
2. 该仓库 **Settings → General → Features** → 勾上 **Discussions**
3. 到 **Discussions** 标签页 → 新建分类，类型选 **Announcements**（只有你能开新帖，防垃圾）
4. 打开 [giscus.app/zh-CN](https://giscus.app/zh-CN)，填入仓库名，抄下三项填进 `src/config.ts`：
   - `data-repo` → `giscus.repo`
   - `data-repo-id` → `giscus.repoId`
   - `data-category-id` → `giscus.categoryId`
5. commit + push，等 Cloudflare 自动重新部署

**验证**：文章页底部出现评论框，用 GitHub 账号能发帖；发完后那个仓库的 Discussions 里能看到这条讨论。

---

## 第 5 步：自定义域名（可选）

1. 买一个域名（`.com` 约 60~80 元/年）
2. Pages 项目 → **Custom domains** → **Set up a domain**，填你的域名
3. 按提示到域名商加 DNS 记录（通常是一条 CNAME 指向 `你的项目.pages.dev`）
4. 等 DNS 生效（几分钟到几小时），HTTPS 证书由 Cloudflare 自动签发
5. 把环境变量 `SITE_URL` 改成你的域名，重新部署一次

**验证**：打开你的域名，有小锁图标；RSS 里的链接也是新域名。

> **国内访问提示**：域名指向 Cloudflare 的话不需要备案。要用国内云厂商的服务器或 CDN 才需要 ICP 备案。

## 日常写作流程

```bash
# 1. 新建文章：src/content/blog/我的新文章.md
# 2. 本地预览：npm run dev
# 3. 发布：
git add . && git commit -m "post: 我的新文章" && git push
```

推送后 Cloudflare 自动重新构建，几十秒后线上更新。构建日志在项目的 **Deployments** 里。

## 本地模拟完整的线上环境（含统计接口）

```bash
npm run build
npm run cf:dev        # wrangler pages dev dist，会同时启动 functions/
```

这样点赞、阅读量走的是真实的 Pages Functions（KV 用本地模拟文件），可以提前验证接口是否正常。

---

## 附：改用 GitHub Pages

项目里保留了 GitHub Actions 工作流（`.github/workflows/deploy.yml`），因为它会自动处理子路径：

1. 仓库 **Settings → Pages → Source** 选 **GitHub Actions**
2. 推送后自动部署到 `https://你的用户名.github.io`（仓库名是 `用户名.github.io`）或 `https://你的用户名.github.io/仓库名/`
3. 在 **Settings → Secrets and variables → Actions → Variables** 里可以设置 `SITE_URL`

**要注意**：GitHub Pages 跑不了边缘函数，点赞/阅读量会降级为本地记录。

## 排错清单

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| Cloudflare 构建失败 | 看 Deployments 里的日志第一处 error | 本地跑 `npm run build` 复现，报错通常很明确 |
| 页面能开但样式全丢、链接 404 | 误设了 `BASE_PATH` | 删掉这个环境变量（Cloudflare 站点在根目录） |
| 点赞一直是 0 / 有"本地预览"提示 | 没绑定 KV 或变量名不对 | Bindings 里变量名必须是 `BLOG_KV`，改完重新部署 |
| 搜索框提示索引未生成 | 构建时没跑 Pagefind | 确认构建命令是 `npm run build`（它会依次执行 astro build 和 pagefind） |
| 评论框显示配置引导 | giscus 四项没填全 | 按第 4 步填写，`repoId` 和 `categoryId` 最容易抄错 |
| RSS 里链接指向 pages.dev | `SITE_URL` 没改 | 改成正式域名后重新部署 |
| 国内打开慢 | 线路问题 | 绑定自定义域名，或确认没走 GitHub Pages |
